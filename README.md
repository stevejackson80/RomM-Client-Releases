# RomM Client — releases

Public downloads for [RomM Client](https://github.com/stevejackson80/RomM-Client), a fullscreen, controller-friendly client for your [RomM](https://github.com/rommapp/romm) server.

- **Windows:** download `RommClient-Setup-<version>.exe`.
- **Linux:** download `RomM-Client-<version>-x86_64.AppImage`, make it executable and run it.
- Each release has a `SHA256SUMS.txt` to check your download.

The app checks this repository for new versions (Menu → Check for updates).
